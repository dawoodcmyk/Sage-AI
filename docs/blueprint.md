# **App Name**: Sage

## Core Features:

- AI-Powered Chat: Intelligent chat using an internal tool for comprehensive knowledge retrieval and reasoning to format answers, accessible through slash commands (e.g., /imagine).
- Chat Interface: Provide a clean and intuitive chat interface for easy interaction.
- Session History: Enable storing all question and answer history within the app.
- Display Questions and Answers: Clearly display the current question with its corresponding response in the interface.

## Style Guidelines:

- Primary color: Dark blue (#1A237E) for a modern, serious, and trustworthy feel.
- Background color: Very dark blue (#121842), near black but still carrying the primary hue.
- Accent color: Light blue (#64B5F6) for interactive elements and highlights, contrasting for readability and a touch of modernity.
- Font: 'Inter' sans-serif for both questions and answers, ensuring a clear and readable interface.
- Simple, single-column layout for easy reading and a streamlined user experience.
- Subtle animations when new messages appear to enhance user engagement without distraction.
